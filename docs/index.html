Almost every time you select text you are about to copy it or look it up. Snipbar puts a tiny bar right under the selection with exactly those actions: copy, search, or ask ChatGPT. On every site, with no menus in between.

Download for Chrome Source on GitHub
Already installed? Select any sentence on this page and the real bar shows up. Press Esc to dismiss it.

Three buttons. That is the whole interface.

No right-click menu, no keyboard chord to remember, no popup to open. The bar appears when a selection exists and disappears the moment it does not.

Copy

Copy

One click puts the selection on your clipboard and the button says Copied for a beat before the bar gets out of the way. Works in textareas and inputs too.

Google

Search

Opens the selection as a search in a new tab. Google by default. Swap it for DuckDuckGo, Bing or Brave from the toolbar popup and the button relabels itself.

ChatGPT

Ask

Sends the selection straight into ChatGPT as a prompt via chatgpt.com/?q=, so the answer is loading before you have switched tabs. Claude and Perplexity are one setting away.

Works everywhereEvery site, inside iframes, in text fields, with mouse or keyboard selections.
Knows its placeCentred under the selection, flips above near the bottom edge, tracks scrolling.
Leaves when toldEscape, a click elsewhere, or a collapsed selection all dismiss it. It will not nag about the same selection twice.
Nothing phones homeNo analytics, no remote code, no network requests from the extension. Settings sync only through your Chrome profile.

Install in about a minute

The Chrome Web Store listing is not up yet. Loading it unpacked takes four steps and works in Chrome, Edge, Brave and Arc.

  1. Download the zipGrab snipbar.zip from the latest release and unzip it somewhere it can stay.
  2. Open the extensions pageGo to chrome://extensions and switch on Developer mode in the top right corner.
  3. Load unpackedClick Load unpacked and choose the unzipped folder. Snipbar appears in the list.
  4. Select somethingOpen any page, highlight a sentence, and the bar shows up underneath it.

The only two settings

Click the toolbar icon to pick where Search and Ask go. That popup also links back here and to the source.
